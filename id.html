1LSPMulai

Setiap file .lsp berisi satu atau dua command. Nama command adalah kata pertama di nama file, jadi SL_SPEC_LEADER...lsp berisi command SL.

SL

Semua yang ada di kotak kuning adalah command. Ketik di command line lalu tekan Enter, sama seperti mengetik LINE atau COPY.

Download command .zip dari GitHub · selalu versi terbaru
  1. Extract ke folder yang tetap, misalnya D:\LSP Suite, jangan di folder Downloads. AutoCAD mengingat lokasi file-nya, jadi kalau nanti dipindah atau dihapus, command-nya tidak bisa dimuat lagi.
  2. Ketik APPLOAD di AutoCAD.
  3. Untuk memuat file hanya di sesi ini, pilih file lalu klik Load.
  4. Supaya dimuat otomatis setiap AutoCAD dibuka, klik Contents... di bagian Startup Suite lalu tambahkan file-filenya di sana.

Muncul peringatan keamanan?AutoCAD bertanya dulu sebelum memuat file dari folder yang belum dikenal. Klik Load atau Always Load. Supaya tidak ditanya lagi, tambahkan foldernya di OPTIONS → Files → Trusted Locations.

Sebagian besar command TOC dan spec mencari block berdasarkan nama: TOC, SPEC, block kop, dan beberapa lainnya. Block, layer dan linetype-nya, ada di file starter yang tidak ikut di repo ini. Mulai gambar baru dari file itu, atau insert block-nya dari sana, sebelum memakai command-command tersebut.

File starterAda di Google Drive kantor. Kalau tidak ketemu, tanya Yeza.

Daftar block di bagian bawah berisi semua nama block dan tag attribute yang dibutuhkan.

2LSPAlat cepat

Ketik command-nya lalu jawab pertanyaannya. Tidak perlu setup selain block yang disebut di tiap kartu.

ADMenomori block sesuai urutan klik

Drawing Tools/AD incremently increase numbers in any block.lsp

Pilih block sumber, lalu klik block lain satu per satu. Semua angka di semua attribute naik sebesar step dikali jumlah klik. Dengan step 1, klik pertama dapat +1, klik kedua +2, dan seterusnya. Nilai lama di block tujuan tidak dipakai. Nol di depan tetap dipertahankan, jadi A-01 menjadi A-02.

  1. Step per klik. Enter berarti 1. Bisa negatif.
  2. Pilih block sumber.
  3. Klik block tujuan secara berurutan. Enter untuk selesai.

Attribute dengan tag SKALA tidak pernah diubah. Tambahkan tag lain di daftar bagian atas file kalau perlu.

CCMenyalin judul gambar

Drawing Tools/CC copy drawing title.lsp

Menyalin judul gambar dari satu block JUDUL ke block lain. JUDUL adalah label judul di bawah setiap gambar di model space.

  1. Pilih block JUDUL sumber.
  2. Klik block tujuan. Enter untuk selesai.

Block dengan attribute JUDULGAMBAR.

DIVV / DIVHMembagi kotak menjadi ruang sama besar

Drawing Tools/DIVV DIVH divide box into equal sized compartments.lsp

Untuk tampak kabinet. DIVV menambah sekat vertikal, DIVH menambah ambalan horizontal. Setiap sekat digambar sebagai dua garis dengan jarak setebal sekat, dan semua bukaan hasilnya sama besar.

  1. Jumlah ruang. Default 3.
  2. Tebal sekat. Default 20.
  3. Pilih outline kabinet.

Command ini memakai bounding box outline, jadi hanya cocok untuk persegi panjang yang tidak diputar.

DSGaris bertahap untuk sisi melengkung

Drawing Tools/DS Taper Lines for rounded edge.lsp

Menggambar garis-garis sejajar di samping garis acuan, dengan jarak yang makin lebar sesuai rasio. Cara biasa untuk menampilkan permukaan lengkung di gambar tampak.

  1. Pilih LINE acuan. Polyline tidak bisa.
  2. Jumlah garis. Default 8.
  3. Rasio pertambahan. Default 1.35. Harus di atas 1.
  4. Jarak ke garis terakhir. Tanda plus/minus menentukan sisi. Default 100.

Jawaban terakhir dipakai sebagai default untuk berikutnya.

NUMGRIDGrid angka

Drawing Tools/NUMGRID number grid.lsp

Menulis grid angka berupa TEXT, dari kiri ke kanan lalu baris demi baris ke bawah. Memakai layer, text style, dan ukuran teks yang sedang aktif.

Pertanyaan: angka awal, step, jumlah kolom, jumlah baris, jarak X, jarak Y, titik awal.

PFMenaruh daftar furnitur

Drawing Tools/PF place Furniture TOC.lsp

Membuat daftar furnitur di halaman index Shop Drawing Furniture. Meng-insert satu kolom block FURNLIST berjarak 140 unit, dengan kode seperti CA1, CA2... dan judul seperti cabinet 1, cabinet 2....

Pertanyaan: prefix kode, judul dasar, nomor awal, nomor akhir, titik insert pertama.

Block FURNLIST dengan attribute FURNCODE dan FURNTITLE, digambar dengan skala 1:20.

3LSPTOC dan layout

Command-command ini menjadikan daftar isi (TOC) di model space sebagai daftar induk semua sheet. Judul sheet cukup diketik sekali di TOC, lalu command-nya menyalin judul itu ke kop layout yang sesuai.

Block TOC

TOC adalah satu kolom block TOC di model space, digambar dengan skala 1:20. Setiap block adalah satu baris dengan dua attribute:

TagIsiContoh
PAGECODEKode sheet, SDF- atau SDB- ditambah dua digit. Harus sama dengan nama tab layout (huruf besar/kecil tidak berpengaruh).SDF-03
PAGETITLEJudul sheet yang tampil di kop.Tampak kabinet 3

Block TOC juga menyimpan kode spec yang dibaca SL. Penjelasannya ada di menyiapkan kode spec.

Alur kerja

Kapan mulaiBuat TOC saat gambar sudah sekitar 80 sampai 90% selesai. Sebelum itu, sheet masih sering ditambah, dihapus, dan diurutkan ulang setiap revisi, jadi TOC-nya harus diulang terus.

Di tahap ini seharusnya sudah ada satu layout untuk setiap sheet, masing-masing hasil copy dari layout template, dengan urutan yang benar.

  1. Taruh barisnya. Di model space jalankan PT dengan prefix SDF, awal 1, akhir 12. Hasilnya SDF-01 sampai SDF-12 dengan judul kosong.
  2. Isi judulnya. Double-click baris pertama dan ketik judulnya. Lalu pakai CT untuk menyalin apa adanya, atau CP / CPP untuk menyalin dengan angka yang naik setiap klik.
  3. Ganti nama layout. Jalankan WQB dengan prefix SDF- (kali ini pakai strip) dan awal 1. Nama tab menjadi SDF-01 sampai SDF-12, sama dengan TOC.
  4. Sinkronkan setiap sheet. Atur skala viewport, lalu jalankan WS di layout itu. Skala ditulis ke kop dan judul diambil dari TOC. Untuk sheet tanpa skala jalankan WSS.
  5. Menyisipkan sheet belakangan. Pilih baris-baris setelah sheet baru lalu jalankan CTB dengan +1 untuk menggeser kodenya. Jalankan WQB lagi, lalu WS di sheet yang berubah.

PT menambahkan strip sendiri. WQB tidak, jadi ketik SDF- di sana. Keduanya memakai dua digit, jadi SDF-01 di TOC cocok dengan tab SDF-01.

PTMenaruh baris TOC

TOC and Layouts/PT place table of contents block.lsp

Meng-insert satu kolom block TOC berjarak 140 unit dengan kode SDF-01, SDF-02... dan judul kosong.

Pertanyaan: prefix tanpa strip (SDF atau SDB), nomor awal, nomor akhir, titik insert pertama.

Block TOC dengan attribute PAGECODE dan PAGETITLE.

CT / CP / CPPMenyalin judul TOC

TOC and Layouts/CT, CP, CPP

Ketiganya menyalin PAGETITLE dari block TOC sumber ke block yang diklik setelahnya. Pilih sumber, klik tujuan, Enter untuk selesai. Bedanya ada di angka dalam judul:

CommandAngkaSumber Lantai 2 Kabinet 4 menghasilkan
CTtetapLantai 2 Kabinet 4, Lantai 2 Kabinet 4...
CPsemua +1 per klikLantai 3 Kabinet 5, Lantai 4 Kabinet 6...
CPPsemua kecuali yang pertama +1 per klikLantai 2 Kabinet 5, Lantai 2 Kabinet 6...

CP dan CPP menghapus nol di depan (09 menjadi 10, tapi 05 menjadi 6).

CW / CTBMengubah kode TOC

TOC and Layouts/CW_copy_toc PAGE CODE.lsp, CTB_bump_toc_page code number_batch.lsp

CW mirip CP tapi untuk PAGECODE: pilih sumber, lalu setiap tujuan mendapat kode +1, +2, dan seterusnya. Nol di depan tetap ada, jadi SDF-09 menjadi SDF-10 dan SDF-01 menjadi SDF-02.

CTB adalah versi banyak sekaligus. Pilih block sebanyak apa pun dengan window, masukkan angka (default 1, boleh negatif), dan angka itu ditambahkan ke nomor di akhir setiap kode. SDB-05 menjadi SDB-06. Block tanpa PAGECODE, atau yang kodenya tidak berakhir dengan angka, dilewati dan ditampilkan di command line.

WQBGanti nama semua layout

TOC and Layouts/WQB_RENAME_LAYOUT_BATCH with 0 pad.LSP

Mengganti nama setiap tab layout, sesuai urutan tab, menjadi prefix + nomor dua digit.

Pertanyaan: prefix (boleh kosong), nomor awal.

Semua layout diganti namanya WQB tidak menanyakan layout mana. Semua tab di gambar diganti namanya, termasuk cover dan sheet catatan. Cek urutan tab dulu, save sebelum menjalankannya, dan pakai Ctrl+Z kalau hasilnya salah.

Nama sudah dipakaiWQB tidak bisa memberi nama yang sudah dipakai tab lain. Kalau tab-nya sudah bernama SDF-01, SDF-02, dan seterusnya, jalankan WQB sekali dengan prefix sementara seperti x, lalu jalankan lagi dengan SDF-.

WS / WSSSinkron skala dan judul ke sheet

TOC and Layouts/WS autosync..., WSS_autosync..._NTS.lsp

Jalankan di tab layout. Tidak ada pertanyaan.

  1. Skala. WS membaca skala viewport dan menulis 1:50 (atau berapa pun skalanya) ke attribute SCALE di kop. WSS menulis N.T.S.
  2. Judul. Mencari block TOC di model space yang PAGECODE-nya sama dengan nama tab ini, lalu menulis PAGETITLE-nya ke KOPTITLE di kop.

Kalau satu sheet punya lebih dari satu viewport, WS memakai yang ditemukan terakhir. Samakan skala semua viewport atau perbaiki nilainya manual.

Block kop kop angleina1 di layout dengan attribute SCALE dan KOPTITLE, serta block TOC di model space.

4LSPSpec dan leader

Cara kerja spec leader

Satu spec leader terdiri dari tiga objek: lingkaran kecil di benda yang diberi label, polyline putus-putus, dan block SPEC berisi kode dan deskripsi. SL menggambar ketiganya dan memberi ID tersembunyi yang sama (XData dengan nama app POPULATE). Dengan ID itu, RR, RZ, RC, dan EE bisa menemukan dua objek lainnya saat salah satunya dipilih.

Jangan copy spec leader COPY, Ctrl+C / Ctrl+V, dan MIRROR ikut menyalin ID tersembunyinya. Hasil copy dan aslinya jadi punya ID yang sama, dan RR, RZ, RC, serta EE bisa memindah atau menghapus bagian dari grup yang salah. Selalu buat leader baru dengan SL.

Menyiapkan kode spec

SL mengisi deskripsi dengan mencari kode spec di block TOC di model space. Jadi sebelum menaruh leader, buat satu baris TOC untuk setiap material: kode di PAGECODE, deskripsi lengkap di PAGETITLE.

PAGECODEPAGETITLE
pcloPanel fin. HPL Lamitak Mood Cloudy Cement DXP 1387BS

Insert block TOC lalu double-click untuk mengetik, atau copy baris yang sudah ada lalu edit. Copy baris TOC tidak masalah; hanya spec leader yang punya ID tersembunyi. Huruf besar/kecil kode tidak berpengaruh, dan SL menulis kode dengan huruf kapital di block SPEC, jadi pclo tampil sebagai PCLO.

Pakai kode yang gampang diingat Pakai kode paling sederhana yang bisa diulang tanpa perlu dicek: satu huruf atau kata pendek untuk jenis barang, lalu 3 huruf pertama materialnya. p untuk panel, k untuk kabinet, LED untuk spec LED, r untuk router. Panel Cloudy Cement jadi pclo.
Atau tanpa kode Block SPEC bisa diedit seperti block biasa. Tekan Enter saat SL menanyakan kode spec, dan SL menggambar block SPEC kosong. Double-click block-nya lalu ketik deskripsinya. Untuk memakai teks yang sama di block SPEC lain, pakai CS, jangan copy-paste. Mengedit teks tidak mengubah ID tersembunyi, jadi RR, RZ, RC, dan EE tetap jalan. SY hanya mengganti deskripsi yang berasal dari TOC, jadi deskripsi yang diketik manual tidak ikut berubah.

SL / SLSCALEMenaruh spec leader

Specs and Leaders/SL_SPEC_LEADER_w_embedded_index and continous scale state.lsp

  1. Penyebut skala, misalnya 15 untuk 1:15. Hanya ditanyakan pertama kali di satu sesi.
  2. Kode spec, misalnya pclo. Tekan Enter untuk melewatinya dan mendapat block SPEC kosong.
  3. Klik titik di objek. Titik ini menjadi pusat lingkaran.
  4. Klik titik pertama leader, lalu titik-titik berikutnya. Enter untuk selesai.
Ganti skala: SLSCALE SL mengingat skala sampai sesi selesai, jadi tidak akan bertanya lagi. Saat pindah ke gambar dengan skala lain, jalankan SLSCALE dulu dan masukkan penyebut skala yang baru. Kalau tidak, lingkaran, garis putus-putus, dan block SPEC akan keluar dengan ukuran skala lama.

Block SPEC dengan attribute PAGECODE dan SPECDESC, linetype HIDDEN sudah di-load, dan kode spec di TOC (opsional).

Jangan copy lingkaran, leader, dan SPEC untuk membuat yang baru. Lihat peringatan di atas. Jalankan SL lagi.

RR / RZ / RCMenggambar ulang leader setelah dipindah

Specs and Leaders/RR..., RZ..., RC...

Pindahkan lingkaran atau block SPEC ke mana saja, lalu pilih salah satu bagian grupnya. Leader lama dihapus dan diganti yang baru, dengan linetype scale yang sama.

  • RR menggambar garis lurus kalau SPEC sejajar dengan pusat lingkaran. Kalau tidak, bentuknya L: naik atau turun dari lingkaran, lalu mendatar ke SPEC.
  • RZ selalu menggambar bentuk Z: mendatar dari lingkaran, belok vertikal di tengah, lalu mendatar ke SPEC.
  • RC menggambar bentuk C: keluar dari lingkaran di sisi yang berlawanan dengan SPEC, belok vertikal, lalu kembali mendatar ke SPEC. Kalau SPEC tepat sejajar dengan pusat lingkaran, bentuk C tidak bisa dibuat dan tidak ada yang berubah. Pakai RR atau RZ untuk kasus itu.

Ketiganya tidak mengecek objek lain yang menghalangi. Kalau leader barunya menabrak sesuatu, pindahkan SPEC lalu jalankan lagi.

EEMenghapus satu grup leader

Specs and Leaders/EE_erase_spec_leader_group.lsp

Pilih lingkaran, leader, atau block SPEC, dan ketiganya dihapus. Tidak ada konfirmasi. Ctrl+Z untuk mengembalikan.

CSMenyalin deskripsi spec

Specs and Leaders/CS copy spec.lsp

Menyalin SPECDESC dari satu block SPEC ke block yang diklik. Enter untuk selesai. Pakai ini, bukan copy-paste, kalau beberapa leader butuh teks yang sama.

Hanya deskripsi yang berubah. Kode di block tujuan tetap.

SYMengganti spec di seluruh gambar

Specs and Leaders/SY synspec for document wide spec changes.lsp

Untuk saat klien mengganti material. Masukkan kode lama dan kode baru. SY mencari kedua deskripsinya di TOC, lalu mengganti setiap block SPEC di model space yang deskripsinya sama dengan yang lama.

Hanya deskripsi yang berubah. PAGECODE di setiap block SPEC tetap. Kedua kode harus ada di TOC, kalau tidak SY berhenti tanpa mengubah apa pun.
